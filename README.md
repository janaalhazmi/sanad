# سَند (Sanad AI)

**سَند** هو نموذج أولي (MVP) لمساعد ذكي داخل تطبيق مصرفي، يهدف إلى تسهيل الخدمات البنكية باستخدام الذكاء الاصطناعي والأوامر الصوتية، مع التركيز على سهولة الاستخدام وإمكانية الوصول.

## تشغيل المشروع

```bash
pip install flask flask_cors joblib scikit-learn pandas cryptography
python3 app_server.py
```

ثم افتح:

```
http://127.0.0.1:5001
```

### بيانات الدخول التجريبية

- رقم الجوال: **0500000000**
- الرقم السري: **12345**

---

## المميزات

- تسجيل الدخول.
- الاستعلام عن الرصيد.
- عرض البطاقات والحسابات.
- تحويل الأموال.
- إدارة المستفيدين (إضافة / حذف).
- الإشعارات وكشف الحساب.
- مساعد ذكي يدعم العربية والإنجليزية.
- التحكم الصوتي والتنقل بين الصفحات.
- قراءة محتوى الشاشة صوتياً.
- التحقق قبل العمليات الحساسة باستخدام **البصمة (WebAuthn)** أو **رمز التحقق (OTP)**.
- فهم الأرقام العربية والإنجليزية المنطوقة أثناء التحويل.

## ملاحظات

- المشروع عبارة عن **نموذج أولي (MVP)** لأغراض تعليمية.
- يتم استخدام بيانات تجريبية (Dummy Data) ولا يتم ربطه بنظام مصرفي حقيقي.
- يتم محاكاة إرسال رمز التحقق (OTP) داخل النظام ولا توجد خدمة رسائل فعلية.
